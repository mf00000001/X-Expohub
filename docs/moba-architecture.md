## 1. 项目概述

### 1.1 核心玩法

| 功能 | 操作 | 实现 |
|------|------|------|
| 🖱️ 移动 | 鼠标右键点击地图 | A* 寻路 + 路径平滑 |
| ⚔️ 攻击 | 鼠标左键点击敌人 | 自动追击 + 攻击冷却 |
| 🔥 技能 | Q / W / E / R | 冷却管理 + 蓝耗检查 |
| 💰 经济 | 击杀小兵/英雄 | 自动获得金币 |
| 🛒 商店 | P 键打开面板 | 金币购买装备/Buff |

### 1.2 设计原则

- **单机可玩**：前端独立运行，无需后端即可完整体验
- **多人扩展**：后端 WebSocket 房间系统预留多人对战
- **模块解耦**：游戏引擎 / 寻路 / 战斗 / UI 各自独立模块
- **TypeScript 全栈**：前端 TypeScript + Canvas，后端 Python FastAPI

## 2. 技术栈选型

### 2.1 前端

| 层级 | 技术 | 理由 |
|------|------|------|
| **渲染** | HTML5 Canvas 2D | 轻量、浏览器原生、无需额外库 |
| **语言** | TypeScript | 类型安全、IDE 友好 |
| **游戏循环** | `requestAnimationFrame` + 固定时间步长 (1/60s) | 流畅 60fps |
| **HUD** | HTML + CSS 覆盖层 | 样式灵活、DOM 事件方便 |
| **模块化** | ES Modules (`.js` 后缀导入) | 浏览器原生支持 |

### 2.2 后端（可选多人）

| 层级 | 技术 | 理由 |
|------|------|------|
| **框架** | FastAPI (Python) | 异步高性能、自动 OpenAPI 文档 |
| **数据库** | SQLite + aiosqlite | 零配置、适合原型 |
| **ORM** | SQLAlchemy 2.0 (async) | 成熟、类型安全 |
| **实时通信** | WebSocket (FastAPI 原生) | 房间管理 + 位置同步 |
| **数据校验** | Pydantic v2 | 请求/响应自动校验 |

### 2.3 为何不用 Phaser.js / Unity？

- **Phaser**：功能丰富但黑盒，A* 寻路和战斗系统需深度定制
- **Unity WebGL**：太重，加载慢，不适合轻量原型
- **纯 Canvas**：完全可控，每行代码都是项目资产，无框架锁定

## 5. A* 寻路系统（核心）

### 5.1 算法选择：A* on Grid

**为什么不用导航网格 (NavMesh)？**
- NavMesh 生成复杂，需要 Recast 库
- 网格寻路实现简单、可调试、性能足够（65×41=2665 个节点）

### 5.2 算法设计

```
A*(start, end):
  1. 将起点加入 openList
  2. while openList 非空:
     a. 取 f 值最小的节点 current
     b. 若 current == end → 重建路径，返回
     c. 将 current 移入 closedSet
     d. 对 8 个邻居:
        - 检查边界、可通过性、对角线卡墙角
        - 计算 g = current.g + 移动代价 (直=1, 斜=√2)
        - 若 g < neighbor.g: 更新 parent, g, h, f
        - 若不在 openList 中则加入
  3. 无路径 → 返回最近可行走点
```

### 5.3 启发式函数：Octile 距离

```
h = max(|dx|, |dy|) + (√2 - 1) × min(|dx|, |dy|)
```

Octile 距离在 8 方向网格中最优，保证 admissibility。

### 5.4 路径平滑：拉绳法 (String Pulling)

```
1. 从起点开始
2. 找最远的可见路径点（lineOfSight 检查）
3. 将该点加入平滑路径
4. 重复直到终点
```

### 5.5 动态障碍物

- 网格每帧刷新 `walkable` 属性
- 防御塔被摧毁后对应格子变为可行走
- 若目标点不可行走 → 寻找最近可行走点作为终点

## 6. 战斗系统

### 6.1 攻击流程

```
左键点击敌人
  → 设置 attackTarget
  → 检查距离 ≤ attackRange?
    是 → 攻击冷却 ≤ 0? → performAttack()
    否 → 向目标移动
```

### 6.2 伤害计算公式

#### 物理伤害

```
final_damage = raw_damage × 100 / (100 + armor)
```

| 护甲 | 减免% |
|------|-------|
| 0 | 0% |
| 30 | 23% |
| 100 | 50% |
| 200 | 67% |
| 300 | 75% |

#### 魔法伤害（同理，使用 magic_resist）

#### 真实伤害（无视护甲/魔抗）

### 6.3 攻击速度

```
attackCooldown = 1.0 / attackSpeed (秒)
```

例：攻速 0.75 → 冷却 1.33 秒

### 6.4 金币奖励

| 炮车 | 45g | 90xp |

## 7. 技能系统（QWER）

### 7.1 技能数据结构

```typescript
interface SkillData {
    name: string;           // 技能名
    key: 'Q'|'W'|'E'|'R';  // 绑定键
    icon: string;           // 图标 emoji
    cooldown: number;       // 冷却秒数
    currentCooldown: number;// 当前剩余冷却
    manaCost: number;       // 蓝耗
    range: number;          // 施法距离
    damageMultiplier: number;// 伤害系数（×攻击力）
    description: string;    // 描述
    type: 'targeted'|'self'|'direction'|'aoe';
}
```

### 7.2 施法条件检查

```
canCast(hero):
  if hero.isAlive == false → "已死亡"
  if currentCooldown > 0   → "技能冷却中"
  if hero.stats.mp < manaCost → "法力不足"
  return null  // 可以施法
```

### 7.3 冷却管理

```
每帧: currentCooldown = max(0, currentCooldown - deltaTime)
施法: currentCooldown = cooldown
```

### 7.4 示例技能配置（剑圣）

| 槽位 | 技能 | 冷却 | 蓝耗 | 伤害系数 | 类型 |
|------|------|------|------|----------|------|
| Q | 斩击 | 6s | 40 | 1.5×AD | targeted |
| W | 护盾 | 12s | 50 | 0 | self |
| E | 突进 | 10s | 60 | 0.8×AD | direction |
| R | 大招 | 30s | 100 | 3.0×AD | aoe |

## 8. 单位系统

### 8.1 继承层次

```
Unit (基类)
├── Hero (英雄 - 玩家操控)
├── Minion (小兵 - AI 沿兵线)
└── Tower (防御塔 - 固定位置 AI)
```

### 8.2 Unit 基类属性

| 属性 | 类型 | 说明 |
|------|------|------|
| x, y | number | 世界坐标 |
| radius | number | 碰撞半径 (18-24px) |
| team | 'blue'\|'red'\|'neutral' | 阵营 |
| stats | UnitStats | HP/MP/AD/AS/护甲/魔抗/移速 |
| path | Point[] | A* 返回的路径点 |
| attackTarget | Unit\|null | 当前攻击目标 |
| attackCooldown | number | 攻击冷却剩余 |

### 8.3 小兵 AI

```
每帧:
  1. 搜索 300px 范围内的敌方单位
  2. 优先攻击英雄（若在范围内）
  3. 若无目标 → 沿 lanePath 前进
  4. 到达终点 → 消失
```

### 8.4 防御塔 AI

```
每帧:
  1. 搜索攻击范围内最近的敌方单位
  2. 优先攻击小兵（保护英雄塔下机制）
  3. 攻击冷却: 0.8 秒/次
  4. 伤害: 150+ 物理
```
