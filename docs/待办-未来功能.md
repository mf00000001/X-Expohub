## 向量匹配 / RAG（2026-10-19 决定：未来做）

- 决策：暂缓，等核心撮合与数据稳定后再启动
- 方案（已调研，直接可执行）：
  1. 云端 embedding：OpenAI text-embedding-3-small(1536) / 硅基流动 bge-m3(1024) / 阿里百炼 text-embedding-v3，均为 OpenAI 兼容接口，改 base_url + model 即可
  2. 成本：6.7 万展品 ≈ 500–800 万 token，text-embedding-3-small 约 1 元以内
  3. 存储：SQLite product_embeddings 表存 float32 blob；6.7 万×1024 维≈270MB，numpy 余弦 top-k 可常驻内存；更大规模再上 FAISS
  4. 幂等：分批 + 断点续跑 + 失败重试；以 product_id 为键 upsert
  5. 降级：向量服务不可用时回落一期 TF-IDF/关键词检索
- 前置条件：需要 embedding API Key（写 .env，不入库不进 git）
