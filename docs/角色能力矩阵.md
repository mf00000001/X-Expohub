> **审计方式**：后端 `scripts/role_audit.py`（5 角色 + 匿名 token × 全部 79 个 GET 路由自动打矩阵，
> 输出 `role_audit.csv`）；前端路由守卫 / 导航组件 / 页面条件渲染人工核对。

> 审计日期：2026-09-16 ｜ 环境：演示容器（27 展品 / 33 采购）

**设计内限制（403/404 属预期，不属"应通用"范畴）**：

| 端点 | 限定 | 理由 |
|---|---|---|
| `/admin/*` | admin + organizer | 平台治理 |
| `/platform/overview` | admin | 计费/租户 |
| `/exhibitor/analytics/*` | exhibitor(+admin/organizer) | 展商经营数据 |
| `/onsite/*stats`・`/organizer/*` | organizer + admin | 现场运营 |
| `/procurements/{id}/matches`・`/recommendations` | **采购创建者** + admin | 应标清单/推荐属需求方私有 |
| `/messages/conversations/{id}*` | **会话参与方**（已复核：参与方 200，非参与方 403） | 会话私密性 |
| `/poster/exhibitor` | exhibitor | 展商名片工具 |
| `/venues/{id}`（404） | — | 演示库 venues 表为空，非权限问题 |

## 4. 本次修复清单（前端入口断层 5 处）

| # | 文件 | 问题 | 修复 |
|---|---|---|---|
| 1 | `router/index.ts` | `/visitor/procurements*`、`/buyer/procurements*` 4 条路由 roles 只放 visitor/buyer，展商/主办方/管理员被守卫弹回 | roles 放开为全部 5 角色（与后端"登录用户即可"对齐） |
| 2 | `views/user/ProfileView.vue` | 「我的报名/我的采购」只对 visitor/buyer 显示；buyer 缺买家工作台入口、admin 缺管理后台入口 | 报名/采购按钮全角色；补 buyer 工作台、admin 管理后台 |
| 3 | `components/layout/AppHeader.vue` | visitor 顶栏无任何业务入口（仅"我的"）；buyer 缺收藏清单 | visitor 补「我的采购/积分」；buyer 补「清单」 |
| 4 | `views/visitor/MyProcurementsView.vue` | `canPublish` 仅 visitor/buyer → 其他角色看不到发布按钮 | canPublish 全角色 |
| 5 | `api/index.ts`・`api/paged.ts` | 响应信封解包吞掉 `pipeline` 元信息 → 工作流摘要行不渲染（前端联调期间发现） | 解包时透传 `pipeline`（数组可挂载属性）；normList 数组分支携带 |

> 注：`components/NavBar.vue`、`components/RoleGuard.vue` 为**无引用死代码**（当前布局用 `layout/AppHeader`），
> 未改动；如确认可后续清理。
