## 2. 怎么选的子页

txt 是纯文本，抽不出 href，所以重新请求首页 HTML，解析 `<a>` 的**链接文字**。按 URL 路径挑是行不通的：SiteServer 与各类 CMS 的路径是 `/contents/101/14166.html`、`?route=about_exhibition_1`，里面没有 about/概况。

- 关键词：展会概况 / 展会介绍 / 展会简介 / 关于展会 / 上届回顾 / 往届回顾 / 展会数据 / 展会规模 / 展后报告 / About / Overview / Facts / Figures / Statistics / Review / Exhibition Profile / Why Exhibit
- 词形归并（不扩充词表，只合并同义写法）：展览会→展会、博览会→展会、概览→概况
- 每站 ≤3 个子页，≤5 次请求（重试也计数），超时 15s、重试 3 次、并发 6；`_OPENER`、robots、gzip、编码识别、`visible_text()` 全部从 `collect_skeleton.py` 直接 import，保证与批次 1 口径一致

调试中修掉两个真 bug，命中数从 11 → 14：

1. 黑名单里写了 `"en/"`，把 `/humen/list_270.html` 的"展会介绍"整条误杀（URL 里 `hum**en/**list` 命中）
2. 链接文字被 `<span>` 拆开、或中英混排："关于华巨臣茶博会 About Tea Fair"、"展览会简介"、"展会概览" 全部匹配不上 —— 改为去空白 + 词形归并后，英文用字母边界（`\b` 在汉字与字母之间不成立）

## 4. 16 个没补到的站，原因分四类

| 原因 | 站数 | 典型 |
|---|---|---|
| 首页导航纯 JS，`<a>` 里没有概况入口 | 12 | cmef、pharmchina、yiwu-fair、b-catering（`<a>` 文本只有"查看更多/展位预订"） |
| 首页是纯前端壳（`<a>` < 15 个） | 3 | caexpo、bakery-china、cismef |
| 候选域名是集团门户/跳错域，站内没有该展的概况页 | 2（含在上面的 12 里） | b-premium-gift、reed-gift-sz 都落在 `rxhuabo.com.cn` 集团站；sial-china 落在英文门户，导航只有 Exhibitor/Visitor |
| 子页抓到了但正文 < 120 字（跳转页） | 1 | foshan-ceramics |

`no_keyword_links` 的 12 站里有 4 站单页 HTML 已在 100KB 以上（cmef 80KB、sial-china 297KB、simm 修复后已成功、chtf 154KB），不是页面太小，而是导航由脚本渲染 —— **这批站只能靠浏览器渲染（`render_spa.py` 那条路），静态抓取再重试多少次都是 0**。
