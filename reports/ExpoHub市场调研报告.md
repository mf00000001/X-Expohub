## 📈 市场概况

### 市场规模

| 维度 | 数据 | 来源 |
|------|------|------|
| **全球活动管理软件市场** | 2023年约 **$120亿**，预计2030年达 **$250亿**（CAGR 11.2%） | Grand View Research |
| **中国数字会展市场** | 2023年约 **¥350亿**，预计2027年达 **¥800亿**（CAGR 18%） | 艾瑞咨询 |
| **中国展览行业市场规模** | 2023年约 **¥1.2万亿**（含线下经济带动） | 中国会展经济研究会 |
| **中小型展会（500~5000人）数量** | 全国每年约 **3~5万场**，占展会总量 **70%+** | 行业估算 |
| **展会数字化渗透率** | 当前约 **25%**，预计2027年达 **45%** | 行业报告 |

### 增长趋势

1. **线上线下融合（OMO）成为标配** — 纯线下展会正在向混合模式转型，线上能力不再是可选项而是必选项
2. **采购撮合需求爆发** — 展商参加展会的首要目标是"找客户"，采购商的目标是"找产品"，双方匹配效率是核心价值
3. **数据驱动决策** — 展商和主办方越来越重视参会者行为数据、ROI分析、线索转化追踪
4. **移动端优先** — 参会者更倾向于通过手机完成签到、社交、日程管理，微信小程序是重要入口
5. **垂直行业深耕** — 通用平台增长放缓，垂直行业（医疗、汽车、科技、消费品）展会平台崛起
6. **AI赋能展会** — AI推荐匹配、智能客服、自动翻译、内容生成正在重塑展会体验

### 关键驱动因素

| 驱动因素 | 影响程度 | 说明 |
|---------|:-------:|------|
| ✅ 后疫情时代线下展会复苏 | ⭐⭐⭐⭐⭐ | 2024~2025年展会数量爆发式增长，数字化需求同步上升 |
| ✅ 企业数字化转型加速 | ⭐⭐⭐⭐ | 传统展会主办方从Excel+邮件管理转向数字化平台 |
| ✅ 跨境贸易需求 | ⭐⭐⭐⭐ | 线上商贸配对平台需求旺盛，特别是外贸展会 |
| ✅ Z世代参会者 | ⭐⭐⭐ | 对互动体验、社交功能要求更高 |
| ✅ 碳中和政策 | ⭐⭐ | 推动绿色会展，减少纸质物料和差旅 |

### 机会窗口

> **中小型专业展会（500~5000人规模）的数字化管理+商贸撮合需求未被充分满足。**
> - 头部平台（Cvent、31会议）服务大型展会，价格高、功能重
> - 中小平台（展贸通等）功能不全、体验差
> - **ExpoHub 的"轻量+低价+四方角色+采购撮合"组合是精准切入机会**

## 💡 战略建议

### 建议一：聚焦"中小型专业展会+采购撮合"核心赛道

**做什么：**
- 初期只服务 **500~5000人规模** 的专业行业展会（科技、医疗、消费品优先）
- 将 **采购需求发布+展商匹配+在线沟通** 作为核心卖点，而非大而全的展会管理
- 砍掉非核心功能（复杂的财务系统、场地管理、直播），快速上线MVP

**为什么：**
- 市场上已有31会议等平台做展会管理，但**没有平台专注做展会场景下的采购撮合**
- 中小型展会主办方最缺的不是管理工具，而是**帮助展商获取线索、帮助采购商找到产品**的平台
- 采购撮合是高频刚需，能快速建立用户粘性

**不做：**
- ❌ 不做大型展会（5000+人），那是Cvent和31会议的领地
- ❌ 不做虚拟展会/直播（需要大量带宽和技术投入）
- ❌ 不做支付/财务系统（合规成本高）

### 建议二：以"低价+免费增值"策略快速获客

**定价方案：**

| 版本 | 价格 | 适用对象 | 功能限制 |
|------|------|---------|---------|
| **免费版** | ¥0 | 小型展会/初创展商 | 1场展会、最多500参会者、基础功能、带ExpoHub品牌 |
| **专业版** | ¥2,000~¥5,000/场 | 中型展会 | 不限参会者、高级数据报表、自定义品牌 |
| **企业版** | ¥20,000~¥50,000/年 | 大型展商/连锁展会 | 不限场次、API接入、专属客服、私有部署 |

**为什么：**
- 相比31会议（¥5,000~¥100,000/场）和Cvent（$500~$5,000+/年），ExpoHub定价低50%~80%
- 免费版降低使用门槛，快速积累种子用户
- 通过免费版获取用户后，通过增值功能（高级报表、自定义品牌）转化付费

### 建议三：打造"AI+采购撮合"核心差异化

**分阶段AI能力建设：**

| 阶段 | 功能 | 技术方案 | 优先级 |
|------|------|---------|:------:|
| **MVP** | 关键词搜索+品类筛选 | Elasticsearch + 规则匹配 | P0 |
| **V1.1** | AI智能匹配推荐 | 基于用户行为的协同过滤+内容推荐 | P1 |
| **V1.2** | AI采购需求分类 | NLP自动分类采购需求到品类 | P1 |
| **V2.0** | AI智能报价建议 | 基于历史成交数据的价格推荐 | P2 |
| **V2.0** | AI客服助手 | 基于LLM的智能问答 | P2 |

**MVP阶段即可实现的AI能力：**
- 采购需求发布时，自动推荐匹配的展商（基于品类+关键词）
- 展商查看采购需求时，按匹配度排序
- 搜索结果的智能排序（综合考虑相关度、展商活跃度、历史成交）

### 建议五：深耕1~2个垂直行业，建立标杆案例

**推荐切入行业：**

| 行业 | 理由 | 目标客户 |
|------|------|---------|
| **🏥 医疗健康** | 展会多（每年200+场）、采购需求旺、数字化程度低 | 医疗器械展、医药展、健康产业展 |
| **💻 科技/互联网** | 展会活跃、主办方数字化意识强、容易接受新平台 | 人工智能展、消费电子展、SaaS行业展 |
| **🚗 汽车零部件** | 采购需求精准、行业集中、复购率高 | 汽配展、新能源车展 |

**标杆案例策略：**
1. 选择1~2场行业展会，**免费提供平台服务**
2. 协助主办方完成数字化升级，积累案例数据
3. 通过案例数据（匹配率提升、线索量增长）说服更多主办方
4. 与行业协会合作，获取背书和推广渠道

### 建议六：技术架构与市场策略对齐

**当前技术架构的优势利用：**

| 技术特性 | 市场价值 |
|---------|---------|
| **JWT双令牌认证** | 支持高并发、无状态认证，适合展会高峰期的流量冲击 |
| **RBAC四角色权限模型** | 精准的四方权限控制，确保数据安全，是说服主办方和老板的关键卖点 |
| **MySQL核心数据表设计** | 12张核心表覆盖完整业务场景，数据模型清晰，便于后续扩展 |
| **FastAPI异步框架** | 高性能、自动生成API文档，降低开发维护成本 |
| **Uniapp跨端框架** | 一套代码覆盖H5+小程序+App，降低多端开发成本 |

**需要补充的技术能力：**

| 能力 | 优先级 | 说明 |
|:----:|:------:|------|

| WebSocket实时通信 | P0 | 采购沟通、消息通知的实时性需求 |

| 数据分析报表 | P1 | 老板角色的核心需求，需要聚合查询能力 |
| AI推荐引擎 | P2 | 差异化竞争力的核心，但MVP阶段可用规则替代 |

## 📋 总结与行动清单

### 核心结论

| 维度 | 结论 |
|------|------|
| **市场机会** | ✅ **中小型专业展会（500~5000人）的采购撮合需求未被满足，市场空间大** |
| **竞争格局** | ⚠️ 头部平台强但贵且不聚焦撮合，中小平台弱，ExpoHub有机会弯道超车 |
| **差异化方向** | 🎯 **四方角色闭环 + 采购撮合 + 低价** 是核心差异化 |
| **首要目标** | 🚀 **3个月内上线MVP，获取10~20场展会作为种子用户** |
| **长期愿景** | 🌟 **成为中小型专业展会首选的一站式采购撮合平台** |
