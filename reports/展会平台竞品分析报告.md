## 📈 市场概况

### 市场规模

| 维度 | 数据 |
|------|------|
| **全球活动管理软件市场** | 2023年约 **$120亿**，预计2030年达 **$250亿**（CAGR 11.2%） |
| **中国数字会展市场** | 2023年约 **¥350亿**，预计2027年达 **¥800亿**（CAGR 18%） |
| **虚拟/混合会展市场** | 2023年约 **$45亿**，预计2028年达 **$120亿**（CAGR 21%） |

### 增长趋势

1. **线上线下融合（OMO）成为标配** — 纯线下或纯线上展会都在向混合模式转型
2. **AI赋能展会** — AI推荐匹配、智能客服、自动翻译、内容生成正在重塑展会体验
3. **数据驱动决策** — 展商和主办方越来越重视参会者行为数据、ROI分析
4. **移动端优先** — 参会者更倾向于通过手机完成签到、社交、日程管理
5. **垂直行业深耕** — 通用平台增长放缓，垂直行业（医疗、汽车、科技）展会平台崛起
6. **SaaS化+低代码** — 主办方希望快速搭建个性化展会，低代码/无代码趋势明显

### 关键驱动因素

- ✅ **后疫情时代线下展会复苏**，但线上能力成为标配
- ✅ **企业数字化转型加速**，传统展会向数字化管理升级
- ✅ **跨境贸易需求**推动线上商贸配对平台增长
- ✅ **Z世代参会者**对互动体验、社交功能要求更高
- ✅ **碳中和政策**推动绿色会展，减少纸质物料和差旅

### 机会窗口

> **中小型专业展会（500~5000人规模）的数字化管理需求未被充分满足。**
> 头部平台（Cvent、31会议）服务大型展会，小平台功能不全。
> 这是一个 **"高性价比、易用性强、功能完整"** 的展会平台切入机会。

## 👤 目标用户

### 用户画像

| 角色 | 描述 | 核心需求 |
|------|------|---------|
| **🎪 展会主办方** | 行业协会、展览公司、政府机构、企业市场部 | 活动创建、展商管理、票务销售、数据分析 |
| **🏢 参展商/展商** | 各行业企业，希望在展会上展示产品、获取线索 | 展位管理、展品展示、线索收集、商贸配对 |
| **👥 参会者/观众** | 行业从业者、采购商、媒体、学生 | 注册报名、日程查看、社交互动、展商浏览 |
| **🤝 赞助商** | 品牌企业，希望通过展会获取曝光 | 品牌展示、广告位管理、线索收集 |

### 核心痛点

| 痛点 | 具体表现 | 影响 |
|------|---------|------|
| **😩 系统碎片化** | 注册用A系统，签到用B系统，展商用C系统，数据不通 | 主办方管理成本高，数据孤岛 |
| **😩 成本过高** | Cvent等头部平台年费$10,000+，中小主办方负担重 | 被迫使用Excel+邮件管理 |
| **😩 用户体验差** | 注册流程繁琐，App臃肿，信息查找困难 | 参会者流失率高，满意度低 |
| **😩 数据洞察弱** | 只有基础统计，缺乏行为分析、ROI计算 | 无法证明展会价值，续展率低 |
| **😩 社交互动不足** | 展商和参会者之间缺乏有效连接 | 商贸配对效率低，展会价值打折扣 |
| **😩 线上线下割裂** | 线上和线下数据不通，体验不一致 | 混合展会效果打折扣 |

### 使用场景

1. **场景一：行业峰会（500~2000人）**
   - 主办方发布活动 → 参会者注册报名 → 线上直播+线下签到 → 社交互动 → 会后数据分析

2. **场景二：专业展览会（100~500家展商）**
   - 展商在线选位 → 展品上架 → 观众浏览展商 → 商贸配对 → 线索收集 → 交易撮合

3. **场景三：企业年度大会（1000~5000人）**
   - 多会场管理 → 议程定制 → 实时投票/问答 → 网络社交 → 会后回放

4. **场景四：线上商贸对接会**
   - 企业入驻 → AI匹配 → 1对1视频洽谈 → 意向跟进 → 订单转化

## 🧭 SWOT 分析（针对本项目）

### S — 优势
- 🟢 **从零开始无历史包袱**，可以设计现代化的架构和体验
- 🟢 **技术栈先进**（FastAPI + Python），性能好、开发效率高
- 🟢 **轻量灵活**，可以快速迭代，避免大平台臃肿问题
- 🟢 **可深度定制**，针对特定行业/场景做差异化

### W — 劣势
- 🔴 **品牌知名度为零**，获客成本高
- 🔴 **无行业积累**，缺乏对会展行业的深度理解
- 🔴 **功能从零构建**，初期功能覆盖度远不如成熟竞品
- 🔴 **无客户案例**，难以说服大型主办方

### O — 机会
- 🟢 **中小型展会市场空白**，头部平台服务不到位
- 🟢 **AI+展会**是新兴赛道，可以抢占先机
- 🟢 **国产替代趋势**，国内企业倾向选择本土SaaS
- 🟢 **混合展会需求持续增长**，市场教育已完成
- 🟢 **低代码/无代码趋势**，可以降低主办方使用门槛

### T — 威胁
- 🔴 **巨头入场**（腾讯、阿里）可能挤压市场空间
- 🔴 **现有竞品降价**或推出轻量版抢占中小市场
- 🔴 **获客成本高**，SaaS行业竞争激烈
- 🔴 **用户迁移成本高**，主办方一旦使用某平台不易更换

## 💡 战略建议

### 1️⃣ 聚焦"中小型专业展会"赛道，做减法
- **不要试图对标Cvent做全功能平台**，初期聚焦 500~5000人规模的专业展会
- 优先实现：注册报名 → 展商管理 → 签到 → 基础数据分析 四大核心模块
- 砍掉非核心功能（如复杂的财务系统、场地管理），快速上线验证

### 2️⃣ 以"AI+社交"作为核心差异化
- **AI智能匹配**：展商与参会者的精准推荐（对标Swapcard）
- **AI智能助手**：展会导航、日程推荐、常见问题解答
- **社交互动**：1对1视频洽谈、兴趣小组、名片交换（对标Whova）
- 这是中小平台弯道超车的最佳切入点

### 3️⃣ 采用"免费增值+按需付费"定价策略
- **基础版免费**：支持 1 场活动、最多 500 参会者、基础功能
- **专业版按场次收费**：¥2,000~¥10,000/场（根据规模）
- **企业版年费**：¥20,000~¥80,000/年（不限场次）
- 相比竞品定价低 50%~70%，快速获取种子用户

### 4️⃣ 先做"轻量版MVP"，3个月内上线
- **MVP功能清单**：
  - ✅ 活动创建与管理（基本信息、日程）
  - ✅ 参会者注册（表单+支付）
  - ✅ 展商管理（展位分配+展品展示）
  - ✅ 现场签到（二维码签到）
  - ✅ 基础数据看板（报名数、签到率、展商统计）
- **暂缓功能**：虚拟展厅、直播、AI匹配、复杂社交

### 5️⃣ 深耕1~2个垂直行业，建立标杆案例
- 建议选择 **科技/互联网行业** 或 **医疗健康行业** 作为切入点
- 与行业协会合作，免费为1~2场行业展会提供服务，积累案例
- 通过行业口碑传播，降低获客成本

### 6️⃣ 技术架构建议
- **后端**：FastAPI（已有）+ PostgreSQL + Redis（缓存/会话）
- **前端**：React/Vue + 移动端优先设计
- **实时能力**：WebSocket（用于签到、聊天、实时通知）
- **AI能力**：Python + OpenAI API / 本地模型（用于匹配、推荐）
- **部署**：Docker + 云原生（已有 Dockerfile，可扩展）
